# Orion SysGestion

Repositorio del complemento (add-on) de Home Assistant que abre el sistema de gestión Orion del cliente dentro de los sistemas Nexus, sin pedir clave.

## Instalación

En Home Assistant: **Marketplace → ⋮ → Repositorios**, y agregá:

```
https://github.com/Sysmika/orion-sysgestion
```

Después aparece **Orion SysGestion** en la tienda: Instalar → Configuración (dirección del sistema y API key) → Iniciar → queda en el menú lateral.

Ver [la documentación del complemento](orion_sysgestion/DOCS.md).

Compatible con Home Assistant OS y Supervised en `aarch64` (Raspberry Pi 4/5 y similares) y `amd64` (mini PC).
